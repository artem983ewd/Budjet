# План: Деплой проекта Budjet в интернет

## Стек проекта
- **Frontend**: React 19 + Vite + Mantine (TypeScript)
- **Backend**: NestJS 11 (TypeScript)
- **База данных**: PostgreSQL 15

---

## Что нужно для деплоя

### 1. Frontend (статические файлы)
Публикуется как статические файлы после сборки (`yarn build` → `frontend/dist/`).

| Хостинг | Бесплатно | Ссылка |
|---------|-----------|--------|
| **Vercel** | ✓ | vercel.com |
| **Netlify** | ✓ | netlify.com |
| **Cloudflare Pages** | ✓ | pages.cloudflare.com |
| **GitHub Pages** | ✓ | pages.github.com |

### 2. Backend (NestJS приложение)
Требует Node.js сервер.

| Хостинг | Бесплатно | Ссылка |
|---------|-----------|--------|
| **Railway** | ✓ (лимит) | railway.app |
| **Render** | ✓ (лимит) | render.com |
| **Fly.io** | ✓ (лимит) | fly.io |
| **AWS / VPS** | Платно | AWS EC2, DigitalOcean и т.д. |

### 3. База данных PostgreSQL
- Хостинг с бесплатным тарифом: **Supabase**, **Neon**, **Railway** (как addon)

## Пошаговый план

### Вариант A: Самый простой (Frontend на Vercel + Backend на Railway)

1. **Frontend на Vercel**
   - Подключить GitHub репозиторий
   - Build command: `yarn build`
   - Output directory: `frontend/dist`
   - Добавить переменную `VITE_API_URL=https://your-backend.railway.app`

2. **Backend на Railway**
   - Подключить GitHub репозиторий
   - Build command: `npm run build` (из папки `backend`)
   - Start command: `npm run start:prod`
   - Добавить переменные: `DATABASE_URL`, `JWT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`

3. **PostgreSQL**
   - Использовать Supabase или Neon (бесплатный тариф)
   - Скопировать URL базы в `DATABASE_URL` бэкенда

### Вариант B: Docker (полный контроль)

1. Создать `backend/Dockerfile`
2. Создать `frontend/Dockerfile` (Nginx для статики)
3. Обновить `docker-compose.yml`
4. Деплой на VPS или Cloudflare Containers

## Что выбрать?

| Критерий | Рекомендация |
|----------|--------------|
| Новичок в деплое | **Vercel + Railway** — минимум настроек |
| Хотите свой сервер | **Docker + VPS** |
| Быстро и бесплатно | **Vercel + Railway + Supabase** |
