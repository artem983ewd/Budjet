# Fix AppShell Footer Not Displaying in DashboardPage

## Problem
Footer не отображается в DashboardPage.

## Причина
**Вложенные AppShell** - архитектурная проблема:

1. `Router.tsx` рендерит `DashboardPage` как **дочерний** элемент `MainLayout` через `<Outlet />`
2. `MainLayout.tsx` уже оборачивает всё в `AppShell` (строка 30)
3. `DashboardPage.tsx` **снова** оборачивает контент в свой `AppShell` (строка 17)
4. Footer `DashboardPage` рендерится внутри `AppShell.Main` родительского layout, что вызывает проблемы с позиционированием CSS

## Решение

**Убрать вложенный AppShell из DashboardPage** - DashboardPage должен рендерить только контент, без собственного AppShell.

### Изменения:

1. **frontend/src/pages/DashboardPage/DashboardPage.tsx**:
   - Убрать `AppShell` обёртку
   - Оставить только контент (Container, Title, Text, Card, Stack)
   - Кнопки навигации (Tab 1, Tab 2) переместить в `MainLayout.tsx`

2. **frontend/src/widgets/MainLayout/MainLayout.tsx**:
   - Добавить `AppShell.Footer` с кнопками навигации между табами
   - Или использовать существующий компонент `ui/Footer.tsx`

### Новый код DashboardPage.tsx:
```tsx
import { Container, Title, Text, Card, Stack } from "@mantine/core";

export function DashboardPage() {
  return (
    <Container>
      {/* existing content */}
    </Container>
  );
}
```

### Новый код MainLayout.tsx:
```tsx
<AppShell.Footer p="md" height={60}>
  <Group gap="sm">
    {/* Tab navigation buttons */}
  </Group>
</AppShell.Footer>
```
