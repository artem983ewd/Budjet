# План: Аналитика с выбором периода

## Текущее состояние

**Frontend:**
- AnalyticsPage: `frontend/src/pages/DashboardPage/ui/AnalyticsPage.tsx` — использует мок-данные
- Нет компонента выбора даты
- React Query + Zustand

**Backend:**
- NestJS + TypeORM + PostgreSQL
- Transaction entity: `transactionDate` (timestamp)
- Нет фильтрации по датам, нет эндпоинтов аналитики
