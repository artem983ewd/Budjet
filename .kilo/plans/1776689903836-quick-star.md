# Plan: Decompose budgetStore and create ExpensesPage

## Current State Analysis

### budgetStore Issues (243 lines)
- Mixed concerns: categories + transactions + UI state + delete logic
- No separation between Income and Expense data
- All features (AddCategory, AddSubCategory, DeleteConfirmation) directly depend on this single store
- Widgets (CategoryAccordion, SubCategoryCard) directly use this store

### Router (line 41-42)
```
{ path: "tab1", element: <IncomePage /> },
{ path: "tab2", element: <IncomePage /> },  // <-- Should be ExpensesPage
```

---

## Decisions Made

- **Separate stores** for Income and Expense (fully isolated data)
- **Tab names**: "Доходы" / "Расходы"
- **Default categories**: Income keeps "Еда", Expense gets "Зарплата"
