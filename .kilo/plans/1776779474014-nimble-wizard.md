# Month Selector for Income/Expense Pages

## Current State
- Income/Expense pages display ALL transactions without date filtering
- Total balance is sum of account balances (denormalized)
- No month selection component exists

## Proposed Solutions

### Option 1: Month Selector + Transaction-Based Balance (Recommended)
Add month picker to Income/Expense pages and calculate balance from transactions for selected month.

**Changes:**
1. **Create MonthPicker component** (`frontend/src/features/BudgetUI/ui/MonthPicker.tsx`)
   - Mantine DatePickerInput with `type="month"`
   - Default: current month
   - State managed via Zustand store

2. **Add Zustand store for selected month** (`frontend/src/features/BudgetUI/model/monthStore.ts`)
   - `selectedMonth: Date` (defaults to current month)
   - `setSelectedMonth(date: Date)`

3. **Update IncomePage/ExpensesPage**
   - Fetch transactions for selected month via `useTransactionsByDateRange(startDate, endDate)`
   - Calculate totals from filtered transactions
   - Add MonthPicker component at top of page

4. **Backend already supports date filtering** - no changes needed

**Balance calculation:**
```
Balance for month = SUM(income transactions) - SUM(expense transactions)
```

---

### Option 2: Month Selector + Keep Account Balance
Month picker filters displayed transactions, but account balance remains as sum of all accounts.

**Changes:**
1. Same MonthPicker component as Option 1
2. Same store as Option 1
3. Update pages to filter transactions by month
4. **Balance display unchanged** - still shows total account balance

---

## Recommended Approach: Option 1

**Rationale:**
- User explicitly said "баланс будет сбрасывать при новом месяце" (balance will reset for new month)
- Transaction-based balance is more accurate and reflects actual income/expenses for that period
- Matches user's expectation that balance is month-specific

---

## Implementation Plan

### Phase 1: Shared Components
1. Create `frontend/src/features/BudgetUI/model/monthStore.ts`
   - Zustand store with `selectedMonth: Date`
   - Setter action

2. Create `frontend/src/features/BudgetUI/ui/MonthPicker.tsx`
   - Mantine `DatePickerInput` with `type="month"`
   - Connects to monthStore

### Phase 2: Update Income/Expense Pages
3. Update `IncomePage.tsx`:
   - Import `useSelectedMonth` from store
   - Import `useTransactionsByDateRange` hook
   - Calculate `startDate`/`endDate` from selected month
   - Pass filtered transactions to component

4. Update `ExpensesPage.tsx`:
   - Same changes as IncomePage

### Phase 3: Balance Calculation
5. Add computed balance display:
   - `balance = totalIncome - totalExpenses`
   - Display prominently on both pages

### Phase 4: Backend (No changes needed)
The backend already supports date range filtering via `startDate`/`endDate` query params.

## Technical Details

**Month date range calculation:**
```typescript
const startOfMonth = new Date(year, month, 1);
const endOfMonth = new Date(year, month + 1, 0, 23, 59, 59, 999);
```

**Mantine DatePickerInput config:**
```typescript
<DatePickerInput
  type="month"
  value={selectedMonth}
  onChange={setSelectedMonth}
  placeholder="Выберите месяц"
/>
```

**React Query key pattern:**
```typescript
queryKey: ["transactions", year, month]
```
