# Frontend Documentation Plan

## Task
Create comprehensive MD documentation for the frontend application with mermaid diagrams.

## Research Completed

### Tech Stack
- **Framework**: React 19.2.0
- **UI Library**: Mantine 9.0.2
- **Routing**: React Router DOM 7.9.4
- **State Management**: Zustand 5.0.12 (UI state) + TanStack React Query 5.99.0 (server state)
- **HTTP Client**: Axios 1.15.1
- **Icons**: Tabler Icons React 3.41.1
- **Bundler**: Vite 8.0.0
- **Testing**: Vitest 4.1.0
- **Package Manager**: Yarn 4.13.0

### Architecture
- Feature-based architecture with clear separation of concerns
- Two-level state management: Server (React Query) + UI (Zustand)
- Layered structure: entities → features → widgets → pages

### Key Components Identified
1. **MainLayout** - App shell with sidebar navigation
2. **DashboardLayout** - Dashboard with bottom tab navigation
3. **CategoryAccordion** - Collapsible category component
4. **SubCategoryCard** - Transaction input card
5. **AddCategoryModal** - Category creation modal
6. **IconRenderer/IconSelector** - Icon selection system

### State Management Pattern
- `useUIStore` - Modal states, editing states, selected icons
- `useAccountsStore` - Account create/edit modal
- `useDebtsStore` - Debt create/edit modal
- `useIncomeStore` / `useExpenseStore` - Domain-specific state (may be legacy)

### Routing Structure
```
/ → LoginPage
/register → RegisterPage
/forgot-password → ForgotPasswordPage
/main → MainLayout (with sidebar)
  /main/dashboard → DashboardLayout
    /tab1 → IncomePage
    /tab2 → ExpensesPage
    /accounts → AccountsPage
    /debts → DebtsPage
    /analytics → AnalyticsPage
  /main/profile → ProfilePage
  /main/settings → SettingsPage
```

### API Pattern
- Axios singleton with JWT interceptors
- Token refresh queue for concurrent requests
- Custom ApiException class
