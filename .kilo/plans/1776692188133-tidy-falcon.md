# План: Валидация ошибок регистрации/авторизации на фронтенде

## Проблема
- Ошибки с бэкенда не отображаются пользователю (только `console.error`)
- `apiClient` не парсит тело ошибки,只 throws generic message
- Нет обработки разных типов ошибок (validation, invalid credentials, duplicate email)

## Текущая архитектура

### Backend
- `ValidationExceptionFilter` - обрабатывает `BadRequestException`, возвращает `{ errors: { field: message } }`
- `UnauthorizedException` (invalid credentials) - возвращает `{ message: "Invalid credentials" }`
- `ConflictException` (duplicate email) - возвращает `{ message: "Email уже существует" }`

### Frontend
- `apiClient` - throws generic `Error(`API Error: ${status}`)`, не парсит тело
- `useLogin`/`useRegister` - только `console.error`, ничего не возвращают
- Формы - не принимают ошибки для отображения

---

## План реализации

### 1. Backend: Улучшить формат ошибок

**1.1 Создать `AllExceptionsFilter`** (`backend/src/filters/all-exceptions.filter.ts`)
- Ловит все необработанные исключения
- Для `UnauthorizedException` → `{ errors: { general: "Неверный email или пароль" } }`
- Для `ConflictException` → `{ errors: { email: "Пользователь с таким email уже существует" } }`
- Для остальных → `{ errors: { general: "Что-то пошло не так" } }`

**1.2 Подключить фильтр в `main.ts`**
- Заменить/дополнить существующую регистрацию

### 2. Frontend: Улучшить API client

**2.1 Обновить `apiClient`** (`frontend/src/shared/lib/api/client.ts`)
```typescript
// Добавить интерфейс для ошибки
interface ApiError {
  errors?: Record<string, string>;
  message?: string;
}

// Модифицировать apiClient для обработки ошибок
// При неудачном ответе парсить JSON тело и выбрасывать структурированную ошибку
```

### 3. Frontend: Обновить хуки форм

**3.1 Обновить `useRegister`** (`frontend/src/features/Auth/model/register.ts`)
- Добавить состояние для ошибок: `{ errors: Record<string, string> }`
- Возвращать `{ handleSubmit, loading, errors }`
- Парсить ошибку из `apiClient` и записывать в state

**3.2 Обновить `useLogin`** (`frontend/src/features/Auth/model/login.ts`)
- Аналогично `useRegister`

### 4. Frontend: Обновить компоненты форм

**4.1 Обновить `RegisterPage`** (`frontend/src/pages/RegisterPage/RegisterPage.tsx`)
- Принимать `errors` из хука
- Добавить `error={errors.firstName}` к `TextInput firstName`
- Добавить `error={errors.lastName}` к `TextInput lastName`
- Добавить `error={errors.email}` к `TextInput email`
- Добавить `error={errors.password}` к `PasswordInput password`
- Добавить `error={errors.general}` под формой (например, в `Text c color="red"`)

**4.2 Обновить `LoginPage`** (`frontend/src/pages/LoginPage/LoginPage.tsx`)
- Аналогично для `email` и `password` полей
- `general` ошибка для "Неверный email или пароль"
