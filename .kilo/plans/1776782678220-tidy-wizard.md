# План: Редизайн цветового дизайна — Grayscale + Синий Accent

## Текущее состояние

- **Framework**: Mantine UI v9.0.2 (React)
- **Конфигурация тем**: `frontend/src/theme.ts` — пустая (`createTheme({})`)
- **Переключение темы**: `useMantineColorScheme()` / `useComputedColorScheme()`
- **Цветовые переменные**: используются дефолтные Mantine (`--mantine-color-*`)

---

## Выбор пользователя

- **Тип темы**: Grayscale (оттенки серого)
- **Accent color**: Синий классический (`#3B82F6`)

---

### 2. Расширить Mantine theme configuration

```typescript
export const theme = createTheme({
  colors: {
    // Кастомные color palettes для primary, accent и semantic colors
  },
  black: '#0F0F0F',
  white: '#FFFFFF',
  primaryColor: 'brand',
  fontFamily: 'Inter, sans-serif',
  radius: {
    xs: '4px',
    md: '8px',
    // ...
  },
  shadows: {
    // Кастомные тени для карточек, модалок
  },
  other: {
    // Дополнительные CSS переменные
  }
});
```

### 3. Добавить CSS переменные для кастомных семантических цветов

В файле `frontend/src/index.css` (или создать новый файл) определить:

```css
:root[data-mantine-color-scheme="light"] {
  --color-bg: #FFFFFF;
  --color-surface: #F3F4F6;
  --color-text: #1A1A2E;
  --color-text-muted: #6B7280;
  --color-border: #E5E7EB;
  --color-accent: #3B82F6;
  --color-success: #10B981;
  --color-warning: #F59E0B;
  --color-danger: #EF4444;
}

:root[data-mantine-color-scheme="dark"] {
  --color-bg: #0F0F0F;
  --color-surface: #1A1A1A;
  --color-text: #F9FAFB;
  --color-text-muted: #9CA3AF;
  --color-border: #2D2D2D;
  --color-accent: #60A5FA;
  --color-success: #34D399;
  --color-warning: #FBBF24;
  --color-danger: #F87171;
}
```

### 4. Подключить кастомные тени и стили компонентов

В `theme.ts` настроить `components` для:
- Карточки (`Card`) — тени, border-radius
- Кнопки (`Button`) — hover states
- Инпуты (`Input`) — border, focus states
- Модалки (`Modal`) — backdrop blur

Проверить `.storybook/preview.tsx` для корректного отображения обеих тем в Storybook.

## Детализация используемых навыков

- **frontend-design**: применение принципов контрастности, типографики и визуальной иерархии
