# План: Интеграция авторизации и подключение Income/Expense к Backend

## Текущее состояние

### Backend (NestJS + PostgreSQL)
- **Аутентификация**: JWT готова (login/refresh), но нет `/auth/register`
- **CRUD**: Есть только Users (полный), Categories и Transactions — только entity
- **База**: `synchronize: false` — нужны миграции
- **Icons**: Поле `icon` отсутствует в Category entity

### Frontend (React + Vite + Mantine)
- **TanStack Query**: Установлен, но НЕ настроен (нет QueryClient provider)
- **Auth**: Моковая реализация — просто записывает в localStorage
- **State**: Zustand хранит категории/транзакции локально, не синхронизированы с backend

---

## Этап 1: Backend — Регистрация и Auth Guard

### 1.1 Добавить endpoint `/auth/register`
- Создать `RegisterDto` в `auth/dto/`
- Добавить метод `register` в `AuthService`
- Добавить route `POST /auth/register` в `AuthController`

### 1.2 Добавить поле `icon` в Category entity
```typescript
@Column({ nullable: true })
icon: string;  // имя иконки из AVAILABLE_ICONS
```

### 1.3 Создать Services и Controllers для Categories и Transactions

**Categories:**
- `CategoriesService`: `create`, `findAll`, `findOne`, `update`, `remove`
- `CategoriesController`: CRUD endpoints с `/categories`

**Transactions:**
- `TransactionsService`: `create`, `findAll`, `findByUser`, `update`, `remove`
- `TransactionsController`: CRUD endpoints с `/transactions`

### 1.4 Добавить Auth Guard к защищённым routes
- Применить `@UseGuards(AuthGuard('jwt'))` к Categories и Transactions controllers

### 1.5 Рефакторинг Category entity (иерархия)
Текущая структура: `parent_id` для self-referencing иерархии
- `MainCategory` = category с `parent_id = NULL`
- `SubCategory` = category с `parent_id = category.id`

## Этап 2: Frontend — TanStack Query

### 2.1 Настроить QueryClient в App.tsx
```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
const queryClient = new QueryClient();
```

### 2.2 Обновить API client
Добавить поддержку Bearer token:
```typescript
const token = localStorage.getItem('access_token');
headers: { ..., Authorization: `Bearer ${token}` }
```

### 2.3 Создать Auth API и hooks
- `POST /auth/login` → `useLogin`
- `POST /auth/register` → `useRegister`
- Сохранять `access_token` в localStorage
- Создать `AuthContext` для хранения состояния пользователя

### 2.4 Создать Categories API hooks
- `GET /categories` → `useCategories`
- `POST /categories` → `useCreateCategory`
- `PATCH /categories/:id` → `useUpdateCategory`
- `DELETE /categories/:id` → `useDeleteCategory`

### 2.5 Создать Transactions API hooks
- `GET /transactions` → `useTransactions`
- `POST /transactions` → `useCreateTransaction`
- `DELETE /transactions/:id` → `useDeleteTransaction`
