# Plan: Добавить маршруты tab1/tab2 и исправить перекрытие footer

## Проблема
1. DashboardPage использует вложенный `AppShell` с `AppShell.Footer` — это перекрывает sidebar из `MainLayout`
2. Footer должен отображаться только на dashboard и его дочерних страницах (tab1, tab2)

## Структура маршрутов после изменений
```
/main
  /main/dashboard        -> DashboardLayout (с footer) + Outlet
    /main/dashboard/tab1 -> Tab1Page
    /main/dashboard/tab2 -> Tab2Page
```

## Изменения

### 1. Создать DashboardLayout
- `frontend/src/pages/DashboardPage/DashboardLayout.tsx` — новый layout-компонент
- Содержит `AppShell.Footer` с кнопками табов (Tab 1, Tab 2)
- Рядом с footer — `<Outlet />` для дочерних маршрутов
- **Не содержит** `AppShell.Navbar` — использует только footer

### 2. Создать страницы табов
- `frontend/src/pages/DashboardPage/ui/Tab1Page.tsx`
- `frontend/src/pages/DashboardPage/ui/Tab2Page.tsx`
- Простые страницы с заголовком и контентом (без footer, AppShell)

### 3. Обновить Router.tsx
```tsx
{
  path: "dashboard",
  element: <DashboardLayout />,
  children: [
    { index: true, element: <Navigate to="tab1" replace /> },
    { path: "tab1", element: <Tab1Page /> },
    { path: "tab2", element: <Tab2Page /> },
  ],
},
```

### 4. Удалить/переименовать старый DashboardPage
- Старый `DashboardPage.tsx` станет `DashboardLayout.tsx` (или создать новый)
- Tab1Page и Tab2Page — внутри `DashboardPage/ui/`
